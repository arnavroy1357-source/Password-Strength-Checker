#  Password Strength Analyzer

A modern cybersecurity-themed Password Strength Checker built with Flask, HTML, CSS, and JavaScript.

## Features

* Real-time password strength analysis
* Modern glassmorphism user interface
* Animated InfoTech loading screen
* Password strength meter
* Password entropy calculation
* Secure password generator
* Copy generated password to clipboard
* Responsive design for desktop and mobile
* Flask backend API integration

## Requirements

* Python 3.10 or higher
* Flask

## Installation

1. Clone or download the project.

2. Install Flask:

   pip install flask

3. Run the application:

   python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000

## How It Works

The application evaluates passwords based on:

* Minimum length of 8 characters
* Presence of lowercase letters
* Presence of uppercase letters
* Presence of numbers
* Presence of special characters
* Bonus points for longer passwords

## Strength Levels

0-2  : Weak
3-4  : Medium
5-6  : Strong
7    : Very Strong
